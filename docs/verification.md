# 验证说明

本文件说明 **1.2.0 分支预览**的检查范围与执行方式。源码位于 `version-control` 分支，等待审阅与合并；GitHub 已发布的 Windows 便携版仍为 1.1.0。下文的独立设置窗口和新增调节功能属于 1.2.0。自行构建后，程序生成在 `release/Elysia_desktop_pet-1.2.0.exe`。检查结果以运行输出和 `artifacts/` 中生成的报告为准。

## 环境与命令

需要 Windows、Node.js 22 或更新版本；浏览器检查使用 Microsoft Edge。先执行 `npm ci` 安装依赖。

```powershell
npm test
npm run test:smoke
npm run test:visual
npm run test:faces
node scripts/motion-integrity-check.cjs
node scripts/motion-settings-check.cjs
node scripts/eye-warp-check.cjs
npm run test:settings
node scripts/hit-region-check.cjs
node scripts/drag-interaction-check.cjs
node scripts/key-cloud-check.cjs
node scripts/taskbar-layer-check.cjs
npm run test:zoom
npm run make:portable
node scripts/verify-package.cjs
```

`npm test` 只运行 `tests/` 下的测试。浏览器和桌面检查使用隔离的测试状态，便携包验收使用隐藏窗口，不向系统注入鼠标或键盘输入。

## 表情、形态与动作

- 默认脸与十种表情可独立切换，再次选择同一表情恢复默认脸。
- 猫猫与眼镜是独立开关；四种动作互斥，切换表情或装扮保留动作。
- 检查眼形、嘴型、眨眼、道具遮挡以及各种组合的面部合成。
- 使用实际 WebGL 画面检查头发、刘海、衣摆与双腿轻摆；检查固定的脸部、耳朵与道具区域。
- 预览截图与待机录像供人工核对画风、轮廓和动作衔接。

## 托盘、缩放与窗口

- 托盘左右点击均打开原生菜单，菜单只有“设置”和“退出”两项。托盘图标为透明底粉色图案，检查边缘与裁去多余留白后的可见效果。
- “设置”打开独立窗口，与人物同时存在；重复打开复用同一窗口，关闭后可以重开，人物不会退出。
- 设置窗口无系统标题栏，顶部空白区域可拖动；最小化、最大化／还原、关闭三个 SVG 图标为可点击的非拖动区域。窗口状态通知同步最大化／还原图标和无障碍名称。
- 移动、调整或关闭设置窗口不移动人物、不重新加载人物页面，也不替换人物画布。人物穿透状态不影响设置窗口操作，找回操作会恢复人物交互。
- 外观、动画、桌面三个页面覆盖表情、装扮、动作和偏好；快捷键或其他入口造成的状态变化会同步到设置窗口。
- 升级继续使用原来的用户设置目录，保留位置、大小、装扮开关和偏好；旧配置缺少的新增参数采用默认值。
- 只有按住人物上的鼠标右键再滚动时缩放；释放、失焦和取消手势后停止缩放。
- 连续滚轮输入不丢失，迟到的异步回复不覆盖较新的设置。
- 覆盖 1%、普通尺寸和超大尺寸，验证光标锚点、画布预算、缩小后的清屏和恢复 100% 功能。
- 覆盖连续拖动、跨 DPI 屏幕、四边出屏、窗口恢复与置顶维护。

1.2.0 的设置窗口“桌面”页包含“任务栏层级”选择。`taskbar-layer-check.cjs` 使用独立透明窗口读取真实 Windows 窗口顺序，检查主、副任务栏的前后关系、周期维护、临时遮挡后的恢复，以及隐藏和关闭置顶后的行为。检查只调整测试窗口，不移动任务栏、不注入输入，并核对键盘焦点没有被抢走；报告位于 `artifacts/taskbar-layer-check.json`。

“动画”页通过滑块和数值框调节摆动幅度与速度。执行 `node scripts/motion-settings-check.cjs` 检查实际渲染中的幅度、速度变化和关闭摆动的行为；结合 `npm test` 核对 0–200% 幅度、0.25–3× 速度的范围、100%／1× 默认值、上下部位同向运动，以及最大幅度下的网格和点击范围。检查还关注修改速度或切换表情、动作时是否保持摆动进度，并确认眨眼和目光跟随不随摆动速度变化。实际结果以 `artifacts/motion-settings-check.json` 和 smoke 输出为准。

“眼睛跟随幅度”在原有眼睛扭曲算法上增加 0–200% 强度设置，默认 100%。`node scripts/eye-warp-check.cjs` 对比真实 GPU 输出与原始着色器，检查默认效果一致、0% 停止扭曲、加强后的效果、关闭跟随和闭眼表情，以及调节时不额外读取像素或上传纹理。单元测试和隐藏窗口 smoke 覆盖旧偏好迁移、范围约束、持久化，以及目光跟随开关不重置强度。

`node scripts/settings-window-check.cjs` 用浏览器和模拟主机桥接检查真实设置页面：滑块与数值输入的单位换算、范围端点和默认按钮、独立的表情／装扮／动作、大小输入、状态同步和保存失败后的恢复。窗口按钮检查包含三个 SVG 图标、拖动区域排除、最小化／最大化／还原／关闭的请求，以及模拟外部窗口事件后的图标切换。默认尺寸、紧凑尺寸和大窗口的截图与结果写入 `artifacts/settings-window-check/`；浏览器检查不代替原生窗口验收。

`npm run test:smoke` 使用独立配置和隐藏的原生窗口，核对两项托盘入口、设置窗口生命周期、两个窗口相互独立、隔离的 preload 与 IPC、参数传递和磁盘保存、外部外观更新，以及穿透与恢复操作。检查结束后恢复测试前的偏好和外观。真实用户配置不会被 smoke 测试覆盖。

超大人物通过虚拟尺寸和屏幕可见区域分离来绘制。画布限制为最长边 4096 像素、总面积 800 万像素，不随人物比例无限分配内存。极大缩放采用固定大小的离屏人物及局部采样。

Windows 的原生窗口有最小尺寸限制；1% 人物仍按约 4.2×5.6 DIP 绘制，点击区域投影到人物本身。点击轮廓覆盖动画运动范围，极端放大时不保证逐像素穿透。

## 拖动与点击区域

拖动时主进程直接采样系统光标；普通拖动复用当前画面，松开后继续动画。测试确认拖动不会反复分配画布，外观切换、释放、取消和失焦仍能正确更新。

点击区域由角色轮廓与运动包络生成，透明空白可操作后方窗口。喇叭特效在人物左侧额外预留 140 逻辑像素的绘制空间，人物仍使用原有 600×800 坐标和缩放比例；只将人物与可见特效的轮廓加入点击区域。检查多种外观、眼神方向和动画帧是否仍在原生窗口区域内；缓存命中时不重复读取人物画布。

## 便携包验收

按键云朵的本地检查覆盖最新字符替换、大小写与标点、空格、功能键过滤、关闭清空和一秒过期。喇叭动作额外检查向外移动、全程淡出、切换动作时保留当前字符，以及云朵和扩音弧线的完整运动范围是否包含在原生窗口区域内，动画不逐帧重建窗口轮廓。`npm test` 在 Windows 上还运行真实 Win32 字符翻译与监听生命周期检查，不向用户窗口注入输入。

`verify-package.cjs` 从最终 EXE 提取应用内容，核对文件清单、源码与素材字节、代码许可证及版权说明。随后分别运行隐藏的目录应用和便携程序，检查启动、桌面交互、缩放与独立设置窗口。

验收会核对运行前后的原有桌宠进程，保留用户正在使用的实例。结果与 SHA256 写入 `artifacts/release-check.json`，校验文件生成在 `release/`。
