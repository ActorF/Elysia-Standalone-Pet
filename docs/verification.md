# 验证说明

本页记录 0.8.0 的检查范围与复现方法。便携版和校验文件见 [GitHub Releases](https://github.com/ActorF/Elysia-Standalone-Pet/releases)。

## 环境与命令

需要 Windows、Node.js 22 或更新版本。浏览器检查使用 Microsoft Edge，桌宠日常运行不依赖它。

```powershell
npm ci
npm test
npm run test:smoke
npm run test:visual
npm run test:faces
node scripts/outfit-integrity-check.cjs
node scripts/motion-integrity-check.cjs
```

- `npm test`：表情、动作与装扮独立性，数字行／小键盘与 F 键映射，设置和 IPC 校验，屏幕边界，以及图层刚性旋转检查。
- `npm run test:smoke`：通过独立测试配置、隐藏窗口启动真实 Electron，检查素材、预加载桥梁、IPC、分层绘制与安全设置，然后退出。
- `npm run test:visual`：检查 10 种表情、2 种装扮开关、4 种动作、右键面板、焦点内组合键与眼神方向，并输出截图。额外使用延迟的模拟桌面桥梁测试启动恢复、快速重置与皮肤保存。
- `npm run test:faces`：直接读取实际合成画布，对表情、动作和装扮的 176 种组合执行 613 项像素及渲染检查。
- `node scripts/outfit-integrity-check.cjs`：检查素材校色前后的透明度、道具保护范围、裙子及丝袜主色，并确认运行时使用了校色结果。

浏览器里的组合键检查不替代 Windows 的实际全局快捷键验证。被其他程序占用的快捷键可关闭，或改用设置面板与备用 Ctrl + Alt 组合键。

## 状态与按键

数字 1–0 对应害羞、生气、睡觉、惊讶、晕、Wink、伤心、爱心眼、微笑、囧。F1／F2 分别切换猫猫与眼镜；F3–F6 分别选择待机、喇叭、蛋糕、奶茶。所有快捷键都需要空格前缀，Backspace 全部重置。完整按键表见 [README](../README.md#按键)。

自动检查覆盖以下行为：

- 每个表情及其恢复默认操作保留当前动作和两种装扮；重复选择动作不会回到待机。
- 猫猫与眼镜可同时开启，分别关闭。保存后重新加载，开启与关闭两种结果都正确恢复。
- 启动读取旧设置期间到达的快捷键，等皮肤恢复后按顺序执行；快速切换后立即重置，迟到的设置回包不会恢复旧装扮。
- 右键菜单反映当前选择；鼠标经过不出现按钮。人物点击不改变表情。
- 按住空格执行组合键不会额外激活已聚焦按钮；单独按空格仍可操作聚焦按钮与复选框。

## 表情、道具与颜色

176 种组合来自 11 种脸部状态（默认与 10 种表情）、4 种动作，以及猫猫和眼镜各自的开关。检查在每种动作与装扮下切换所有表情，确认身体像素不变、前景道具不被脸部覆盖、猫耳一直保留。

睡觉采用 `assets/v7/character-sleep.png` 的新参考眼形与嘴型，并显示独立的羊和 ZZZ 装饰。生气与晕也采用新的参考素材；晕的装饰单独绘制。微笑、Wink 的闭眼侧、自动眨眼及默认喇叭闭眼继续使用 `assets/v6/character-closed.png`。Wink 的睁眼侧保留原图，自动眨眼保留当前嘴型；喝奶茶的嘴与短吸管、吃蛋糕的叉子和食物始终维持连接。

爱心只修改虹膜内部和嘴部，原眼睛边界保留。每个组合的表情合成源图从原画坐标 `y=710` 到底部的 RGBA，与相同动作、相同装扮的默认脸逐字节一致。服装使用材质校色，保留各姿势原有的阴影、格纹和轮廓；不要求不同姿势的全部像素相同。

脸部检查还验证新参考眼形和嘴型确实进入运行画面、眨眼时嘴部不被替换，以及合成缓存有界。像素检查仍需结合截图查看睫毛、遮罩边缘、装饰布局和手与道具连接。

## 运动与视觉复核

本版取消人物的加权网格变形。完整前发（包括刘海和贴脸发束）、后发、原图双腿、裙摆及猫尾使用分别绘制的图层。每层围绕固定支点旋转，变换矩阵没有缩放和错切；两个腿保留在同一块原图层内。脸、精灵耳、猫耳和手持道具使用固定图层。眼神追踪只采样虹膜内部，不参与人物形变。

旋转周期为 7.6 秒，各层有轻微相位差。前发摆幅约 ±1.43°，双腿约 ±2.18°，裙摆约 ±1.03°。猫尾使用补全描边的独立素材，尾根向左延伸并被右披肩遮住。

`motion-integrity-check.cjs` 对四种动作采样 17 帧，拦截实际 Canvas 绘制矩阵，验证每层只有一个刚性变换；在腿部旋转坐标系中测量轮廓宽度，光栅误差不超过 2.5 个原图像素（默认窗口小于 1 像素）。固定耳朵内部 RGBA 差不超过 1，来自预乘透明度取整。检查输出四组峰值截图和完整周期录像。

`motion.test.mjs` 检查矩阵正交、行列式为 1、点间距离不变、旋转支点不动，以及关闭摆动和完整周期的结果。实际渲染复核另看两个摆动峰值的头发内外轮廓、固定耳朵、腿宽、裙摆与披肩接缝，不能用“像素发生变化”代替动作质量判断。

```powershell
npm run preview:expressions
npm run preview:motion
```

脚本将截图、时间帧与录像写入本地 `artifacts/`。脸部逐项结果位于 `artifacts/face-integrity/results.json`，服装结果位于 `artifacts/outfit-integrity/results.json`。公开预览见 [表情图](media/expressions.png) 和 [待机录像](media/idle.webm)、[猫猫分层摆动](media/cat-motion.webm) 及 [摆动峰值](media/rigid-peaks.png)。

## 打包与桌面验收

```powershell
npm run make:portable
node scripts/verify-package.cjs
```

构建结果写入 `release/`。校验脚本比较源码与包内运行文件，核对目录包和便携包的内容，并执行隔离的隐藏启动检查。每次发布重新生成校验值。

手动验收覆盖透明窗口、拖动、缩放、托盘、装扮与设置保存、鼠标穿透及 Ctrl + Alt + P 恢复。分别选择四种动作，再切换表情与装扮，确认当前动作保留；关闭并重新运行，确认两种装扮恢复。更新前先退出旧实例，避免同时运行导致快捷键冲突。
