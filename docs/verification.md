# 验证说明

本页说明当前实现的检查范围和复现方法。发布包及其校验文件以 [GitHub Releases](https://github.com/ActorF/Elysia-Standalone-Pet/releases) 为准；本页不固定某个构建的文件数量、大小或哈希。

## 环境与命令

在 Windows 上安装 Node.js 22 或更新版本、Microsoft Edge，然后在仓库根目录执行：

```powershell
npm ci
npm test
npm run test:smoke
npm run test:visual
npm run test:faces
node scripts/outfit-integrity-check.cjs
```

- `npm test`：按键映射、重复切换与重置、状态稳定性、设置校验、屏幕位置、IPC 边界，以及待机网格的位移和几何稳定性。
- `npm run test:smoke`：使用独立测试配置启动真实 Electron 窗口，检查预加载桥梁、IPC、素材加载和 WebGL，随后退出。
- `npm run test:visual`：在 Edge 中检查表情切换、喇叭、重置、设置面板、焦点内组合按键、复选框操作和眼神方向，并生成截图。
- `npm run test:faces`：检查爱心眼的局部修改范围、眨眼时的嘴型、统一闭眼素材的使用、摸头画面的绘制一致性、14 种非道具表情共用的身体，以及全部 17 种表情能否正常渲染。刘海眉的位置、睫毛装饰与眼皮折线仍需结合局部截图复核。
- `node scripts/outfit-integrity-check.cjs`：检查奶茶、蛋糕、猫猫与喇叭 4 种姿势的裙子及丝袜主色、透明度和道具保护范围，并确认运行时已加载校色结果；生成全身对照、衣服局部对照和差异图。

浏览器检查需要本机 Edge，桌宠日常运行不依赖它。全局快捷键可能被其他应用占用；浏览器中的组合键检查不能代替目标 Windows 环境中的实际全局按键操作。

依赖检查（2026-10-19）：Electron 已更新至 43.8.0，包含上游 [预加载缓存问题的修复](https://github.com/electron/electron/security/advisories/GHSA-qmv3-fv6v-rmhq)。`npm audit` 仍报告 8 项中等告警，来自构建工具的 `sprintf-js`／日志依赖链；这些构建依赖不随桌宠运行代码打包。相关记录见 [上游公告](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)。

## 0.6.0 的验收内容

当前功能实现已通过单元测试、Electron 启动检查、全部 17 种表情的界面回归，以及脸部像素与绘制检查。人工视觉复核覆盖：

- 默认脸、爱心眼、睡觉、眯眯眼、Wink、伤心眼、摸头，以及其他表情总览。眯眯眼采用统一参考闭眼形状，伤心眼使用贴近眼角的短泪。
- 爱心只改变虹膜内的小区域与嘴部，原眼睛边界保留，嘴周围没有明显旧图残影。
- 所有包含闭眼的状态共用 `assets/v6/character-closed.png` 中用户确认的眼形：自然睫毛弧、紫色星点和圆点高光，以及紧贴闭眼眼缘的细折线。覆盖睡觉、眯眯眼、摸头、眯眼笑、Wink 闭眼侧、自动眨眼及喇叭；Wink 的睁眼侧保持原眼形，自动眨眼保留当前嘴型。刘海上的灰色细眉保持原位置，下层折线不固定在默认睁眼高度，也不另作一组眉毛。人工复核关注左右眼形、装饰、遮罩边缘和旧睫毛残留；素材中的闭口微笑按对应表情使用。
- 摸头全身画面没有额外叠加手掌；实时眨眼时原有嘴型、眼镜和腮红保持。
- 固定鼠标的 6 秒实录，以及上半头发、刘海、后发、衣摆、腿部的时间帧。默认 420 × 560 窗口下，Edge WebGL 的 8 秒采样中刘海横向峰峰位移约 10.5 像素、两侧发梢约 14–15 像素，周期约 7 秒。眉眼的局部位移受到保护，原有下身轨迹的回归检查保持通过；全网格三角形检查未出现翻转，采样画面未见明显轮廓撕裂或连接破口。

颜色检查区分共用身体与不同道具姿势。14 种非道具表情只合成局部脸部；在 1090 × 1443 原画坐标中，从 `y=710` 到底部的 RGBA 与默认身体逐字节一致。该检查直接读取合成源画布，避免二次缩放造成采样误差。

4 种道具姿势保留各自的手势、阴影、格纹和轮廓，只对深蓝裙与丝袜进行材质校色。内部采样区的 RGB 中位色与默认图每通道相差不超过 1/255；当前参考中位色为裙子 `(65, 66, 109)`、丝袜 `(82, 63, 74)`。校色前后全图 alpha 逐像素一致，服装范围外及指定道具区域的 RGB 差异最多为 Canvas 预乘 alpha 转换造成的 1/255 舍入。不同姿势的阴影和图案仍有区别，因此不声称它们的所有衣服像素完全相同。

以上视觉结论来自实际渲染截图和录像采样，不是仅凭脚本退出成功推断。公开预览见 [表情图](media/expressions.png) 和 [待机录像](media/idle.webm)。

## 重新生成视觉证据

```powershell
npm run preview:expressions
npm run preview:motion
```

脚本将截图、时间帧、录像及检查记录写入本地 `artifacts/`。这些是每次运行生成的检查产物，无需历史安装包或旧版归档。请实际查看图片和视频，特别留意脸部合成边缘、闭眼线条、手与道具连接、发梢和衣摆运动。

脸部检查结果位于 `artifacts/face-integrity/`；材质检查结果位于 `artifacts/outfit-integrity/`，其中 `results.json` 记录逐项结果、颜色样本、舍入范围和校色模块哈希。`full-after.png`、`outfit-before-after.png` 及各姿势的 `*-difference.png` 用于人工复核阴影与接缝；差异图不突出仅有 1/255 的转换舍入，完整计数仍保留在 JSON 中。

## 构建与手动检查

```powershell
npm run package
npm run make:portable
```

目录包与便携版写入 `release/`。源码整理或构建配置变化后，应重新执行测试并检查新生成的包，不能沿用旧包的校验值。

运行便携版后，确认透明窗口、拖动、缩放、托盘、设置保存、鼠标穿透及 **Ctrl + Alt + P** 恢复正常；切换表情和喇叭，确认素材完整。使用全局快捷键前先退出旧实例，避免注册冲突。关闭应用后检查其进程是否正常退出。
