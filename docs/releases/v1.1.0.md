# 爱莉希雅桌宠 1.1.0

新增按键云朵：输入字符时，爱莉希雅会用云朵显示最近按下的一个字符。

- 支持数字、大小写英文字母、标点与空格；空格显示为 `␣`。
- 待机、吃蛋糕和喝奶茶时，浅粉白色圆云朵显示在手心上方，约一秒内消失。
- 喇叭动作时，云朵从喇叭口边缘向左上飘出，带扩音弧线，一秒内逐渐淡出。特效仅为图像，不播放声音。
- 可在系统托盘开关按键云朵。输入只用于即时显示，不记录或保存按键历史。
- 为外飘特效保留透明空间；透明空白可点击穿透，人物位置、比例、自由拖动及缩放保持原有行为。

Windows 便携版无需安装 Node.js。升级前请从托盘退出旧版，然后运行 `Elysia_desktop_pet-1.1.0.exe`；现有设置会保留。

发布附件为 `Elysia_desktop_pet-1.1.0.exe` 和对应的 `.sha256` 校验文件。
